# Flashcard Study App

This is a simple flashcard app I built as my first vibe coding project.

I wanted a lightweight study tool that fits my own learning style, so instead of using existing apps, I created a small HTML-based flashcard program that runs directly in the browser. You can simply drag the HTML file into your browser and start studying.

The goal of this project was not to build a complex application, but to experiment with vibe coding and create something practical for my own studying.

# Features

Runs locally in the browser

No installation required

Simple flashcard-based studying

Lightweight single HTML file

# Why I built it

I wanted a study tool that was quick to open and easy to customize. This project was also a way for me to explore vibe coding and see how quickly I could build something useful for myself.

# How to use

You can either run the file locally or use the hosted version:

# Option 1 — Online
https://anatoogle.github.io/flashcards/

# Option 2 — Local

Download the HTML file

Drag it into your browser

Start studying
